150KB image questions

Is 150KB a good target for a phone photo?

Often, especially when the image will be displayed at modest dimensions. The source and intended display size still matter.

Can I use 150KB for screenshots?

Yes, but text-heavy screenshots should be checked carefully because artifacts around small characters can become noticeable.
