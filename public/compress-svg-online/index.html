Vector experiment · SVG

Make an SVG leaner without rasterizing it.

SVG is text-based vector markup, so file weight can come from metadata, repeated markup, verbose editor output and unnecessary precision. A useful SVG workflow keeps the vector nature intact.

SVG compression is different from photo compression.

01 / MARKUP

Editor metadata

Design tools can embed metadata, comments and editor-specific namespaces that add bytes without changing the visible artwork.

02 / PRECISION

Too many decimals

Overly precise coordinates can make vector markup verbose. Sensible precision can be enough for the intended output.

03 / SAFE

Preserve editability

Inspect the result in a vector editor or browser after compression to confirm the artwork still behaves as expected.

SVG is especially useful for logos, icons and illustrations. If the destination expects a raster image instead, use an appropriate image format and target size rather than forcing an SVG workflow where it does not belong.
