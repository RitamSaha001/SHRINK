1MB image questions

Can a 5MB photo become 1MB?

Often, but the result depends on dimensions, format and visual complexity. Some images need more room or a smaller pixel size.

Does 1MB work for website images?

It can, but web performance often benefits from smaller display dimensions and modern formats when the destination supports them.
