Which number should you use?

File-size wording isn't always perfectly consistent across websites and operating systems, so check the destination's own instructions when available.

File-size questions

Is KB the same as KiB?

Not always. Decimal units use powers of 1,000, while binary units use powers of 1,024. The destination site may use either convention.

Why leave headroom under an upload limit?

If the requirement is a maximum, ending slightly below it reduces the chance of a boundary-related rejection.

Can I use this with Shrink?

Yes. Use the calculator to understand the target, then open Shrink to compress the PDF or image itself.
