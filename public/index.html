Privacy & how this works

Compression is 100% local. Files never leave this browser tab — everything runs on your device using JavaScript, and nothing is uploaded anywhere.

The optional AI assistant only ever sends a file's measured properties (size, dimensions, page count, and similar metadata) to whichever provider you pick — never the file itself.

API keys you add are stored only in this browser's local storage, on your device — they are never sent anywhere except directly to the provider you're using them with (or relayed untouched, see below).

Without your own key, AI requests go through a small relay that substitutes a shared key for Gemini/Groq and applies a daily limit per browser, identified by a random, anonymous id also stored in local storage. That id carries no personal information.

No tracking. This page sets no cookies and runs no analytics or advertising scripts.
