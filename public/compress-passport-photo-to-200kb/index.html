Practical note

Don't confuse a larger file with a better application photo

Once the photo is sufficiently clear for the destination, extra bytes may add little benefit. Use the smallest target that satisfies both the visual and technical requirements.

200KB passport-photo questions

Should I use the full 200KB?

Only when needed. A smaller file is preferable when it remains clear and the destination accepts it.

Does Shrink change the crop?

Shrink's normal role here is file-size reduction. Follow the destination's required crop and dimensions separately.
