PNG behaves differently from a photograph.

Simple graphics can compress efficiently, but screenshots and transparent artwork have their own constraints.

01 / SHAPE

Sharp edges

Thin lines and text need enough resolution to stay clean after reduction.

02 / ALPHA

Transparency

If the destination needs transparency, don't blindly convert the file to a format that loses it.

03 / TEXT

Screenshots

Judge the actual letters, not just the overall visual impression.

A PNG target is often a better fit for interface graphics than photographs. For photographic content, compare JPG or another supported format if the destination accepts it.

PNG to 100KB questions

Why can a simple PNG still be large?

Large dimensions, transparency and detailed pixel patterns can create a surprisingly heavy PNG.

Should I convert PNG to JPG?

Only if the destination allows it and the image does not need transparency or lossless edges.
