Turn a bulky BMP into a lighter file.

BMP keeps pixel data in a straightforward bitmap container, which can make files much larger than a modern compressed image. Use Shrink when an old asset needs a more manageable file size.

BMP can preserve pixels with little compression, so a simple image can still be large.

02 / WEB

Use a practical format

For web and sharing, a compressed format is usually more appropriate than keeping a heavyweight bitmap.

Verify compatibility

Choose the output your receiving service actually accepts before publishing or uploading.

A format change can produce a much larger size improvement than minor quality tuning alone. For a BMP destined for a form or website, start by deciding which output formats the destination supports.
