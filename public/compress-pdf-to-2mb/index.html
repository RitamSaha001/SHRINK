Give a PDF room to breathe at 2MB.

Two megabytes can be a better target for documents with photographs, scans or charts when a smaller limit would damage readability. The goal is to meet the upload rule without shrinking the document more than necessary.

2MB is often a quality-friendly target.

Use it when the destination accepts a little more room and the document contains visual information worth preserving.

01

Start from the original

Compression works best when the source has not already been repeatedly recompressed.

02

Set the real ceiling

Choose 2MB only when the destination allows it. There is no advantage in making the file smaller than the job requires.

03

Check the visual result

Inspect photos, scanned text and line detail. A smaller file is only useful if the document remains readable.

Good candidates for a 2MB target

Scanned reports

Multi-page forms

A practical middle ground for longer documents with mixed text and imagery.

2MB PDF questions

Should I always try to hit 2MB exactly?

No. If the destination only says “under 2MB,” leaving some headroom is sensible.

Why is my PDF still large after compression?

Scans, photographs and embedded resources can dominate the file even after common compression steps.

Does Shrink upload the PDF?

The normal compression workflow runs locally in the browser.
