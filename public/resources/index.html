Start from the requirement

Most file-size problems become easier when the destination rule is the first thing you write down.

“Maximum 100KB” is a clearer instruction than “make it smaller.” Shrink is designed around that difference: pick the limit, work toward it, then inspect the result. Different files behave differently, so a good target is a goal—not a promise that every source can reach the same number.
