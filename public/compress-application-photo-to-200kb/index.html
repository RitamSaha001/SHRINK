A useful rule

File-size success is only one checkbox

A photo can be under 200KB and still fail a form if its dimensions or format are wrong. Treat Shrink as the file-size step in a larger submission checklist.

Application photo questions

Should I crop before compressing?

Usually, yes when the application provides a required framing. Removing unnecessary pixels can also make compression easier.

Can a phone photo work?

Yes, but start from the original camera image and check the form's latest photo specifications before uploading.
