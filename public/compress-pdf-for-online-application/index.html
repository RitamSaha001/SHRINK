01

Read the exact requirement

Note the maximum size and accepted format before you compress.

02

Leave practical headroom

If the limit is strict, a result comfortably below it can be less stressful at submission time.

03

Verify the document

Check names, dates, signatures, photos and small text on the compressed copy.

If a portal rejects the result even though the file looks close to the limit, check the exact rule again. Some systems restrict formats, dimensions, page count or other properties in addition to file size.

Application PDF questions

Why is my application PDF still too large?

Scanned pages and embedded photos are common sources of size. You may need a stronger target or a better source scan.

Should I use the smallest target?

Only when the destination requires it. Otherwise preserve useful readability and visual detail.
