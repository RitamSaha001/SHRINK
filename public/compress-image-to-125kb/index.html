Why 125KB?

Sometimes the “in-between” target is the right one

Not every destination uses round numbers, and a strict 100KB target can be unnecessarily aggressive when 125KB is accepted. A practical target can save quality without creating a noticeably larger file.

125KB questions

Is 125KB enough for a photo?

It can be for many modestly displayed images, but highly detailed photos may need more space.

Why not just use 200KB?

Use the destination's actual limit. When 125KB is enough, there is no need to consume a larger file budget.
