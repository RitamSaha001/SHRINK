Form upload guide

How to make an image small enough for an online form.

The trick is to solve the form's actual requirements, not to make the image as tiny as possible. Check the file-size ceiling, dimensions, accepted formats, and what the image needs to show.

Open image compressorWhat to check

Read the form rule carefully

“Maximum 100KB” is a different requirement from “JPG only” or “400 × 400 pixels.” Some portals enforce several constraints at once.

File size

Use the stated KB or MB ceiling as your target. Leave a small margin when the rule is strict.

Dimensions

A huge image can remain inconvenient even after compression. Match the requested pixel dimensions when the form specifies them.

Format

If the portal accepts only JPG, don't arrive with a perfectly small PNG that the upload control rejects.

A reliable workflow

1

Start with the cleanest source

Use the original photo or scan rather than a screenshot of a screenshot.

2

Match the file requirement

Choose the target size and output format the portal accepts.

3

Check the finished image

Make sure names, faces, signatures, numbers, and small text are still readable before submitting.

Don't optimize the wrong thing

A form may reject a file because of dimensions or format even when the byte size is perfect. Treat the portal's full rule as the specification.

Useful starting targets

Common limits are useful starting points, not guarantees. Pick the exact target your destination specifies.
