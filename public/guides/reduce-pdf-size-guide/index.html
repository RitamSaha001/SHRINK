PDF guide

Why is my PDF so large — and how can I make it smaller?

PDFs can be surprisingly large even when they look simple. Usually the bytes are coming from images, scans, fonts, or document structure. Start by understanding the file, then choose a target that matches what you actually need.

Three common reasons a PDF is large

The page count alone does not tell you much about file size.

Scanned pages

Each scanned page can contain a full-resolution image rather than lightweight text.

Embedded photos

Photographs and screenshots can dominate the document's data even when the surrounding text is small.

Export structure

Fonts, duplicate resources and other objects can add bytes depending on how the PDF was created.

A sensible reduction workflow

1

Measure the starting point

Check the current size and compare it with the destination limit. Reducing 1.2MB to 900KB is a different problem from reducing 12MB to 500KB.

2

Choose a realistic target

Use the actual upload requirement where you have one. Don't force a tiny target if the document needs more data to remain legible.

3

Inspect the finished PDF

Check small text, signatures, charts and scans. Compression is successful when the file is smaller and still fit for purpose.

Target-size beats random presets

A generic “high/medium/low” setting tells you how aggressively to compress, but it does not tell you whether the result will pass the destination's file-size rule.

When a smaller PDF isn't the answer

Sometimes the right fix is upstream: export a scan at a sensible resolution, remove unnecessary pages, or use the original source instead of repeatedly compressing an already compressed file. A very small target can be incompatible with a readable, image-heavy document.
