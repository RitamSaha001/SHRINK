Exact image size FAQ

Does “exact” guarantee every target?

It means the workflow is target-size driven. The achievable result depends on the original image, dimensions, format and content.

Can I target KB and MB?

Yes. Shrink's target-size interface supports size targets expressed in KB or MB.

What formats are supported?

Shrink supports common image formats including JPG, PNG, WEBP, GIF, BMP and SVG.
