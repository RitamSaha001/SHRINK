File size isn't the same as pixel dimensions

Two 2000-pixel images can have very different file sizes. Format, colors, transparency, texture and visual complexity all affect how much data is needed. The best result is the smallest file that still looks right at its intended display size.

100KB image questions

Can every image reach 100KB?

No. The achievable result depends on the source image, its dimensions, its format and how much detail needs to be retained.

What formats does Shrink support?

Shrink supports common image formats including JPG, PNG, WEBP, GIF, BMP and SVG.
