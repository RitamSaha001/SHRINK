Think beyond the kilobytes.

01

Read the complete rule

Some application forms specify file size, width, height and accepted formats at the same time.

02

Compress toward the ceiling

Use the smallest sensible target that still lets the face, signature or document remain clear.

03

Inspect at display size

Check the actual uploaded appearance instead of judging a tiny photo while zoomed far in.

For strict application photos, dimensions can be as important as file size. If the form gives a pixel requirement, follow it before trying to push the image smaller.

Application image questions

Why is my photo still rejected after compression?

Check the dimensions, file format and any separate naming or aspect-ratio rules. File size may only be one part of the requirement.

Should I use the smallest target possible?

No. Use the smallest target that satisfies the form while keeping the image clear.

Make the upload a checklist, not a gamble.

Prepare the image, verify the requirements, then submit the finished file.
